# 51mai 分站功能 1:1 复制任务清单

## 一、项目目标

项目路径：

`/Volumes/My Passport/Project/51mai website clone`

参考分站：

`https://3316049.m3xm.cn/index`

目标不是复制页面视觉，而是：

**保留当前 51mai 已开发的页面结构和视觉风格，但功能必须严格按照参考分站当前实际可见、可进入、可操作的功能进行 1:1 复制。**

禁止根据源码中隐藏模块、通用模板、插件路由自行扩展需求。

唯一功能范围判定标准：

1. 参考分站当前页面真实显示；
2. 用户当前能够实际进入；
3. 页面存在实际操作入口；
4. 功能确实处于启用状态。

如果参考分站当前没有某项功能，则不得擅自开发。

例如：
- 不要添加“影票管理”
- 不要添加未确认启用的电商管理、接单管理等模块
- 不要因为源码中存在路由就认定为需求

---

# 二、开发原则

## 1. 页面结构

保留当前 51mai 页面结构和 UI 风格。

无需把页面视觉重新做成参考分站样式。

重点是功能、字段、状态、行为和数据流一致。

---

## 2. 功能完成标准

任何功能只有同时满足以下条件，才允许标记为“完成”：

1. 有对应入口；
2. 字段与参考分站一致；
3. 状态覆盖参考分站；
4. 按钮可以真实操作；
5. 操作后页面状态发生正确变化；
6. 数据可以保存；
7. 页面刷新后数据不丢失；
8. 前台和后台数据一致；
9. 有自动化测试覆盖；
10. 不允许使用纯静态假按钮冒充功能完成。
