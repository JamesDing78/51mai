## 开发约束

- 视觉方案：现代简洁蓝白风。
- 手机端优先；PC、平板、手机响应式适配。
- 兼容 iOS Safari、Android Chrome、Windows Chrome/Edge、macOS Safari/Chrome。
- 页面结构、信息层级、主要组件、主操作和状态表达以原型为基准。
- 原型若发生调整，先更新本目录，再修改代码。
- 关键流程需补齐加载、空状态、失败、无权限、会话过期等状态。
